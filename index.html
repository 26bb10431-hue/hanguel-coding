한글 프로그래밍 언어 도움말

1. 출력과 입력

  • "내용" 출력하기 : 화면에 글자나 변수의 값을 출력합니다.
  • "질문" 질문 출력하기 : 사용자에게 질문을 하고 입력값을 받습니다.

2. 변수와 조건문

  • 변수이름을 값으로 정하기 : 변수에 값을 저장합니다.
  • 만약 조건이 참과 같다라면 실행하기: : 조건에 따른 분기 처리

3. 함수 만들기 및 호출

  • 함수명(매개변수) 함수 만들기: : 함수를 정의합니다.
  • 함수명("값") : 정의된 함수를 호출하여 실행합니다.
